# Edge Stains / Edge BBOX 옵션 설명표

화면: Void Detection 아래 **Edge Stains** 그룹, Auto Calibration의 **Edge BBOX**.
시작 값은 `config.json`의 `"void_detect": {"edge_band": {...}}`(Edge Stains), `"auto_bbox": {"edges": {...}}`(Edge BBOX)에 적을 수 있습니다(키는 아래 표). 화면 입력칸이 config보다 우선합니다.

## 기준 칩(레퍼런스)이란

"정상 칩은 이렇게 생겼다"는 비교 기준입니다. 칩끼리 거의 같다는 점을 이용해, 여러 칩을 겹쳐 **픽셀마다 중앙값**을 낸 가상의 칩을 만듭니다(오염은 칩마다 자리가 달라 중앙값에서 빠짐). 각 칩을 이 기준 칩과 비교해 **더 어두운 곳 / 구조가 다른 곳**을 점으로 봅니다.
- **흩어짐(spread):** 같은 픽셀이 정상 칩끼리 얼마나 다른지(노이즈, 패드 위치 차이). 차이를 이 값으로 나눠 기준(Dark, SSIM thr)을 "흩어짐의 몇 배"로 씁니다 → 원래 들쭉날쭉한 곳(패드, 경계)은 둔감, 평평한 곳은 민감.
- **reference min / max:** 기준 칩의 주변 3×3 최솟값·최댓값. 칩이 1 px쯤 어긋나도 이 범위 안이면 차이로 보지 않습니다.
- **어떤 칩으로 만드나:** 기본은 네 변을 합쳐 가장 깨끗한 칩들로 **하나의 기준 칩**(Per edge를 켜면 변마다 따로, 그 변이 가장 깨끗한 칩들 — Clean % 0(기본) = 자동(깨끗한 무리: 가장 깨끗한 10% 칩의 1.5배 안, 칩의 1/4(16개 이상) ~ 칩의 절반·64개), Clean %를 넣으면 정확히 그 비율(64개 이하). 위가 오염된 칩도 아래 기준에는 쓰입니다. 오염 칩이 많아 기준 칩(Debug chip 5번)에 오염이 비치면 **Golden**(영상 위 Ctrl+G)으로 확실히 깨끗한 칩을 직접 고르세요(5개 이상 권장).

## Edge Stains 처리 순서

1. **칩 자르기:** bbox마다 영상에 놓인 그대로(회전·보간 없이) 정수 px로 자름 → 칩 외곽으로 대략, 칩 가운데로 ±1 px 미세 위치 맞춤 → 작업 해상도(`work_size`)로 블록 평균 축소 → 칩마다 밝기 정규화.
2. **기준 칩:** Golden 칩의 중앙값, 없으면 가장 깨끗한 칩들(Clean %)의 중앙값. 픽셀마다 칩끼리 흩어짐과 기준의 최솟값~최댓값 범위.
3. **점:** 기준 최솟값보다 Dark × 흩어짐만큼 어두운 곳, 또는(Compare) 질감 세기(SSIM의 대비 항: 국소 대비)가 SSIM thr × 흩어짐만큼 다른 곳(패드가 조금 어긋나는 건 무시). Density 이상 모인 것만.
4. **띠:** 변마다 점을 변 방향으로 길게 이음(Merge r × Along ×), Link gap 이내 조각은 한 띠.
5. **영역:** 칩 경계부터 띠의 가장 먼 점까지(깊이는 변을 따라 중앙값으로 다듬어 튀는 점 무시). Length ≥, Min depth, Aspect를 넘으면 오염. 모서리를 도는 조각은 합침.

## Edge Stains 입력칸


| 입력칸 | config 키 | 기본 | 뜻 | 이럴 때 |
|---|---|---|---|---|
| Length ≥ | `min_length_px` | 100 | 변을 따라 잰 최소 띠 길이(px) | 짧은 오염을 놓치면 ↓ |
| Merge r | `merge_radius_px` | 8 | 점을 선으로 잇는 거리(px, 변을 가로질러) | 띠가 굵게 흩어져 있으면 ↑ |
| Along × | `merge_along` | 2 | 변을 따라서는 Merge r의 이 배수까지 이음 | 듬성한 띠가 끊기면 ↑ |
| Speck ≥ | `min_speck_px` | 0 | **머지 전**: 붙어 있는 어두운 점 덩어리가 이 면적(px²)보다 작으면 버림(0=끔) | 자잘한 점이 띠로 이어지면 ↑(예: 4~10) |
| Piece ≥ | `min_piece_px` | 0 | **머지 전**: 점 덩어리의 변 방향 길이가 이보다 짧으면 버림(px, 0=끔) | 튀는 점이 띠에 붙어 영역을 끌면 ↑(듬성한 띠면 2~5부터) |
| Smooth | `smooth_px` | 40 | 영역 경계(깊이)를 변을 따라 이 길이로 매끈하게 피팅(px, 0=끔) | 경계가 찌글거리면 ↑, 오염 모양을 더 따라가려면 ↓ |
| Link gap | `link_gap_px` | 40 | 변을 따라 이 거리(px) 이내로 끊긴 조각은 한 띠 | 긴 띠가 여러 개/짧게 잡히면 ↑ |
| Depth % | `depth_frac` | 0.25 | 가장자리에서 안쪽으로 볼 깊이(칩 크기 대비; config는 비율) | 깊은 오염이 잘리면 ↑ |
| Dark | `dark_threshold` | 3 | 어두운 점 기준(칩끼리 흩어짐 배수) | 띠가 덜 잡히면 ↓, 엉뚱한 점이 많으면 ↑ |
| Density | `speck_density` | 0.06 | 점이 모여 있어야 하는 비율 | 띠가 듬성하면 ↓ |
| Aspect | `min_aspect` | 1.5 | 길이 ÷ 깊이 최소 | 짧고 두꺼운 오염이면 ↓ |
| Compare | `compare` | "intensity" (dark) | 점 기준: 어두움 + SSIM("both") / 어두움("intensity") / SSIM("ssim") | 눈으로 차이가 거의 없는 띠: both / ssim |
| SSIM thr | `ssim_threshold` | 8 | 구조가 다른 점 기준(흩어짐 배수) | 미검이면 ↓, 과검이면 ↑ |
| SSIM σ | `ssim_sigma_px` | 3 | SSIM 창(가우시안 σ, px) | 띠가 굵으면 ↑ |
| Blur σ | `blur_px` | 0 | 비교 전 가우시안 블러(px, 0=끔) | 노이즈가 심할 때 |
| Skip | `edge_skip_px` | 4 | 칩 맨 바깥에서 제외하는 폭(px) | 칩 테두리가 잡히면 ↑ |
| Min depth | `min_depth_px` | 6 | 가장 얕은 오염(px) | 얇은 줄이 잡히면 ↑ |
| Align tol | `edge_tol_px` | 1 | 칩끼리 어긋남 허용(px): 기준 칩을 ±이만큼(8방향) 옮긴 값 범위 안이면 차이 아님(Shift tol 0일 때) | 경계·패드를 따라 얇은 선이 잡히면 ↑, 약한 오염을 놓치면 ↓ |
| Texture | `texture_px` | 2 | 패드 격자 간격(정수 px): 칩을 줄이기 전에 원본 해상도에서 이 크기 상자로 평균(0·1=끔). 패드가 어디 놓이든 평평해져 간섭 무늬가 안 남음 | 차이 맵(9번)이 격자 모양으로 전부 어두우면 패드 간격으로 |
| Shading | `shading` | 켬 | 칩 안의 밝기 구배(조명) 제거: (칩 − 기준 칩)에 2차 곡면을 강건하게 맞춰 빼고 비교 | 차이 맵에 한쪽이 밝고 반대쪽이 어두운 기울기가 보이면 켬 |
| Along | `edge_along_px` | 4 | 칩 경계에서 이 거리(px) 안은 기준 범위를 변 방향으로만(0=끔) | 경계 바로 옆 오염을 놓치면 ↑ |
| Shift tol | `shift_tol_px` | 0 | 칩끼리 어긋남 허용(px; 0이어도 3×3) | 패드·틈이 잡히면 ↑ |
| Align | `align` | "image" | 칩 위치: image = 영상으로 맞춤(정수 px), bbox = bbox 위치 그대로(Edge BBOX 후) | Debug에 "off by"가 크고 9번에 레이아웃이 보이면 Edge BBOX → bbox |
| Tex σ | `texture_blur` | 1.5 | Texture 상자 평균 뒤 원본 해상도 가우시안(σ px): 패드 간격이 바뀌거나 격자가 틀어진 맥놀이 제거(0=끔) | 9번에 패드 무늬가 남으면 ↑, 가는 띠가 흐려지면 ↓ |
| Fourier | `fourier` | 4 | (칩 − 기준 칩) 스펙트럼에서 주변보다 이 배수 이상 튀는 봉우리(간섭 무늬·패드 격자 맥놀이)를 깎음(0=끔) | 9번에 줄무늬·물결이 남으면 ↓(3), 오염이 깎이면 ↑ |
| Scan lines | `scan_lines` | 켬 | 줄마다 밝기가 다른 스캔선(차이 맵의 가로줄)을 빼고 비교, 줄 사이 변화만 빼서 오염 띠는 남음 | 9번에 가로줄이 많으면 켬 |
| (config만) Warp | `warp_tiles` | 0 | 국부 위치 맞춤: 칩을 Warp×Warp 조각으로 나눠 조각마다 기준 칩에 맞춤(칩이 국부적으로 휘어 패드 간격이 다를 때) | 9번에 레이아웃이 곳곳에 남으면 4~8 |
| (config만) Warp px | `warp_px` | 3 | 한 조각이 움직일 최대 거리(px) | 휨이 크면 ↑ |
| Bg % | `background` | 0 | Shading: 칩−기준 칩의 밝기 차이 중 칩 크기의 이 비율보다 큰 것(얼룩·비네팅)을 오염 빼고 매끈하게 추정해 뺌(config는 비율; 0 = 2차 곡면) | 9번에 큰 얼룩이 남으면 5~10 |
| Edges T B L R | `edges` | "tblr" | 볼 변 | 상하단만: "tb" |
| Match | `match` | "none" | 칩 밝기 맞춤(칩 가운데로): none / linear / curve | 칩마다 전체 밝기가 다르면 linear |
| Per edge | `per_edge` | 끔 | 기준 칩을 변마다 그 변이 가장 깨끗한 칩들로 만들어 이어 붙임(모자이크). 끄면 하나의 기준 칩 | 위 오염 칩·아래 오염 칩이 따로 많아 기준에 오염이 비칠 때 켬 |
| Clean % | `clean_ref` | 0 | 변마다 기준 칩을 만들 "가장 깨끗한 칩": 0 = 자동(깨끗한 무리), 5~95 = 정확히 그 비율, 100 = 전체 표본(모두 최대 64개; config는 비율 0~1) | 기준(5번)에 오염이 비치면 자동(0) 또는 작은 값 |
| Golden | `golden_cells` | 없음 | 기준 칩으로 쓸 칩 [[행, 열], ...] (Ctrl+G로 고름) | 확실히 깨끗한 칩을 알 때 |
| Mark as | `type` | 선택한 타입 | 마킹 void 타입 | |

  (그 밖에 `register_frac` 0.6: 미세 위치 맞춤에 쓰는 칩 가운데 비율, `bright_min` 0: 영역이 기준보다 이만큼 밝아야 인정(0 = 보지 않음), `work_size` 384: 작업 해상도(칩 긴 변).)

## 학습 필터 (Train / Learned / Reset)

1. Detect Edge Stains를 돌립니다(학습 필터가 있으면 Learned를 꺼서 후보를 다 보거나, 켜고 그대로).
2. 리뷰: 맞으면 **A**(칩 일괄) 또는 고쳐서 확정, 틀리면 **지우기**, 놓친 것은 **Paint line**으로 칠하기.
3. **Train**: 이 파일의 후보를 리뷰 결과로 라벨링해 학습 데이터에 넣고 다시 학습합니다. 점선(리뷰 안 함)은 빠집니다. **일부 칩만**: A를 누르거나 칠한 칩이 "리뷰한 칩"으로 기록되고, Train에서 "예"를 고르면 그 칩들만 학습합니다(웨이퍼 전체를 다 볼 필요 없음; 검출 없는 깨끗한 칩도 A를 눌러 넣으면 "오염 아님" 표본이 됨).
4. 다음 파일부터 **Learned**가 켜진 채로 검출: 후보를 넉넉히(Dark·Length × 0.8) 뽑고 필터가 거릅니다.

모델은 제품별(TIF_Viewer_train/products/<제품>/edge_classifier.json). 교차검증 결과(재현율·정밀도)와 많이 쓰인 특징이 Train 후 창에 나옵니다.

## Debug chip 이미지 읽는 법

버튼 = 화면 가운데 칩, 영상 위 **Ctrl+Shift+D** = 마우스 아래 칩. **Detect Edge Stains를 한 번 돌린 뒤에는 모든 칩의 결과가 저장되어 바로 열립니다**(돌리기 전이면 그 칩만 계산, 마킹은 하지 않음). 위쪽 글: 축소 배율, 기준 칩을 몇 개로 만들었는지(이 칩이 기준에 들어갔는지), 버려진 띠와 이유(short = Length ≥ / Link gap, thin = Min depth, not elongated = Aspect).

| 번호 | 이미지 | 무엇인가 | 볼 것 |
|---|---|---|---|
| 1 | raw window | 원본에서 읽은 창(여백 포함, 영상 그대로라 기울어져 보임) | 칩이 창 가운데 있는지 |
| 2 | cut: moved dx, dy | 칩 위치에 맞춰 정수 px로 자른 칩(원본) | 여백이 한쪽만 보이면 bbox가 많이 어긋난 것 |
| 3 | chip as compared | **비교에 쓰는 칩**: ① 원본 해상도에서 패드 간격(Texture) 평균 → ② 작업 해상도로 축소 → ③ 그리드 각도만큼 바로 세움(Upright) → ④ 칩마다 밝기 정규화 (값 − 칩 중앙값) ÷ 칩 흩어짐 → ⑤ 소수 px 위치 맞춤 → ⑥ Blur(설정 시) | 패드 무늬가 남아 있으면 Texture를 패드 간격으로 |
| 5 | median chip | **기준 칩**: 깨끗한 칩들의 픽셀별 중앙값(변마다 그 변이 깨끗한 칩들 / Golden을 고르면 그 칩들) | 오염이 비치면 Golden 고르기 / Clean % 0(자동) |
| 6 | chip-to-chip spread | **흩어짐**: 같은 픽셀이 정상 칩끼리 얼마나 다른지(전체 칩 표본 최대 64개, \|칩 − 기준\|의 25% 분위 ÷ 0.32) | 밝을수록 그 자리는 둔감(패드·경계·비네팅) |
| 7, 8 | reference min / max | **허용 범위**: 기준 칩을 8방향으로 ±Align tol 옮긴 값의 최솟값 / 최댓값 (Shift tol > 0이면 그 반경의 최솟값~최댓값) | 칩이 이만큼 어긋나도 차이 아님 |
| 9 | deviation | **차이** — 픽셀마다, Shading으로 (칩 − 기준 칩)의 밝기 기울기(2차 곡면, Bg % 설정 시 큰 얼룩)를 뺀 칩으로:<br>칩 > 8번 → (칩 − 8번) ÷ 6번 (양수, **빨강** = 밝음)<br>칩 < 7번 → (칩 − 7번) ÷ 6번 (음수, **파랑** = 어두움)<br>그 사이 → 0<br>단위 = 흩어짐의 배수, ±2×Dark에서 꽉 찬 색 | 오염 띠가 파랗게 보여야 함. 다른 무늬가 보이면 아래 상황표 |
| 9b | SSIM change | **질감 변화**: 패드 평균 전 칩의 국소 대비(SSIM의 대비 항)를 기준(같은 칩들의 중앙값)과 비교, 칩끼리 흩어짐으로 나눔. 노랑 = 2×SSIM thr(캡션에 값) | 오염 자리가 노랗게 보이는지 |
| 10 | dark specks | 9번이 −Dark 이하 **또는** 9b가 SSIM thr 이상인 점(가장자리 띠 안만) | |
| 11 | specks kept | 10번 중 Density(주변에 점이 모인 비율)·Speck ≥(덩어리 면적)를 통과한 점 — **머지 전** | 띠의 점이 사라지면 Density / Speck ≥ ↓ |
| 11b | specks left by Piece ≥ | Piece ≥ 설정 시, 변 방향 길이가 짧은 점 덩어리를 뺀 것 — 머지 전 | |
| 12 | joined lines | 점을 변을 따라 이은 띠(Merge r × Along ×) | 끊기면 Merge r / Along × / Link gap ↑ |
| 13 | stain areas | 최종 영역 = 칩 변부터 띠의 가장 먼 점까지(Smooth로 매끈하게) = 마킹 모양 | |

위쪽 글: 축소 배율, 기준 칩을 몇 개로 만들었는지와 이 칩이 기준에 들어갔는지(변별), **off by (dx, dy)** = 자른 뒤 이 칩이 기준 칩과 어긋난 정도(px), 버려진 띠와 이유.

## 상황별로 바꿀 설정

| 상황(어디서 보이나) | 원인 | 바꿀 설정 |

## Edge BBOX 입력·설정

Auto Calibration의 **Edge BBOX**: bbox마다 네 변 근처에서 칩 외곽의 밝기 단차를 찾아 그 가운데로 옮깁니다(원본 영상, 0.1 px 단위). 손으로 놓은 bbox는 그대로. Ctrl+Z로 되돌림.

| 입력칸 / config 키 | 기본 | 뜻 | 이럴 때 |
|---|---|---|---|
| Edge pick / `edge_pick` | "steepest" | 변 근처 단차 중 무엇을 칩 경계로: steepest(가장 가파른 것) / **second (street)**(바깥에서 두 번째: 왼쪽·위 2번째, 오른쪽·아래 1번째 — 칩 사이 길 때문에 단차가 쌍으로 보일 때) / outer / inner(가장 가파른 것의 `pick_frac` 이상인 단차 중 가장 바깥 / 안쪽) | Edge debug에 이중 피크가 보이고 bbox가 밀리면 second |
| `pick_frac` | 0.5 | outer / inner에서 단차로 칠 최소 크기(가장 가파른 것 대비) | |
| `edge_search` | 0.06 | 지금 bbox 변에서 앞뒤로 찾는 범위(칩 크기 대비) | bbox가 많이 어긋나 있으면 ↑(이웃 칩 경계가 들어오지 않게) |
| `edge_band` | 0.3 | 단면을 평균 내는 칩 가운데 띠 폭(칩 크기 대비) | 가운데에 큰 구조물이 있으면 ↓ |
| `size_tol` | 0.02 | 잰 크기가 중앙값과 이만큼 넘게 다르면 한 변이 이상한 칩: 더 가파른 변 + 크기로 둠 | |

- **크기:** 선언 크기(bbox 타입 / 제품)가 잰 크기와 5% 안이면 선언 크기, 아니면 잰 크기의 중앙값(상태바에 표시).
- **단차 방향:** 변마다 길→칩이 밝아지는지 어두워지는지를 칩 다수결로 정해, 길 건너 이웃 칩의 변은 잡지 않습니다.
- **Edge debug** 버튼: 화면 가운데 칩에 대해, 바꾸지 않고 보여 줌 — 창 이미지(노랑 = 지금 bbox, 초록 = 맞춘 bbox, 빨강 = 고른 단차), 네 변 각각의 밝기 단면(흰색)과 단차 크기(주황), 찾는 범위(회색), 고른 단차(초록). 위쪽 글에 각 변의 위치(raw px)·방향·크기와 옮겨질 양. bbox가 밀리면 이 창을 보면 어느 단차를 잡았는지 바로 보입니다.
